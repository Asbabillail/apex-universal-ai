# APEX — Universal AI Intelligence

**v3.0.0-alpha.1 · Experimental pre-release**

> The right prompt. The right model. The right tools.

APEX is an open-source set of three AI skills: Core Prompt Intelligence, AI Model Intelligence, and Tool & Workflow Intelligence. It is not a standalone autonomous agent. Model access and external actions depend on the host environment.

This release is an **alpha**: structural and fixture tests are being established. No live-model performance benchmarks, official certifications, or cross-platform compatibility guarantees are claimed.

See `docs/TESTING.md`, `CONTRIBUTING.md`, and the three folders under `skills/` for details.
