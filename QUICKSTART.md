# APEX Community: 3-minute quickstart

**Free open-source AI skills, built by Babillail AI Studio.** APEX is *instruction text*, not a separate model. You can try it without Python, API keys, or a payment card.

## Download or copy

1. Open the [APEX repository](https://github.com/Asbabillail/apex-universal-ai).
2. For a download, select **Code → Download ZIP**, then extract it.
3. For the easiest setup, open [APEX Community Instructions](distributions/generic/APEX-COMMUNITY-INSTRUCTIONS.md), select **Raw** or copy the instruction text, and paste it as your first message in a new AI conversation.
4. Ask your actual question: **"APEX, Collaborative Mode: I want to build a professional portfolio. Understand my goal and ask up to three essential questions before the final prompt."**

You can also save the instructions inside a supported custom assistant, Gem, or reusable skill, depending on your platform.

> The repository ZIP cannot directly install the private ChatGPT APEX plugin. It does not provide access to connected apps, browsers, GitHub, account data, or automations.

## Tell us when something goes wrong

**[Open the APEX feedback form](https://github.com/Asbabillail/apex-universal-ai/issues/new?template=feedback.yml)** (free GitHub sign-in required). Choose the platform and explain what happened.
