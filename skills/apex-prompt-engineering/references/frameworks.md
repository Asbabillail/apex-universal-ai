# Prompting methods (load only when relevant)
- TAG: Task, Action, Goal — compact everyday instructions.
- RACE: Role, Action, Context, Execution — straightforward work.
- CO-STAR: Context, Objective, Style, Tone, Audience, Response — audience-sensitive writing.
- CREATE: Character, Request, Examples, Adjustments, Type of output, Extras (variants exist) — detailed briefs.
- RISEN: Role, Input, Steps, Expectation, Narrowing — structured procedures.
- CARE: Context, Action, Results, Example — case-study reporting.
- STAR: Situation, Task, Action, Result — chronological experiences.
These are optional planning aids, not empirical guarantees of prompt quality.
