# Evaluation and release protocol
Check skill directory format, frontmatter, required files and manifests. Run static and fixture tests locally for no API cost. Promptfoo Echo validates prerecorded outputs and assertions, **not model behavior**. For live behavior, run an opt-in evaluation against the real host with explicit provider fees, reproducible fixtures and reviewer labels. Track critical requirement coverage, routing, false capability claims, permission mistakes, user clarification burden, latency and token usage. Never issue a performance certificate on static checks alone. Any certificate must record version, commit/release ID, scope of tests, exact results and independent verification links. GitHub test badges only reflect the tests actually executed.
