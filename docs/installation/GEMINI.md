# Use APEX in Google Gemini

Gemini's **Gems** let you save reusable instructions. Gemini does not natively import this repository's ChatGPT \`plugin.json\` as a working ChatGPT plugin.

## Option A: Try APEX immediately

1. Open [APEX Community Instructions](../../distributions/generic/APEX-COMMUNITY-INSTRUCTIONS.md).
2. Copy the text and paste it as your first message in a new Gemini conversation.
3. Follow it with your real goal and specify Quick, Collaborative, or Advanced mode.

## Option B: Make a reusable APEX Gem

1. Visit [Gemini](https://gemini.google.com) on the web and sign in.
2. Select **Gems → New Gem**.
3. Name it something like **APEX Community (Unofficial)**.
4. Paste the complete text from [the generic instructions](../../distributions/generic/APEX-COMMUNITY-INSTRUCTIONS.md) into the Gem's Instructions field.
5. Optionally attach APEX's \`SKILL.md\` / references as Gem knowledge **if** the file controls in your account support them. Upload only public APEX instructions, not private data.
6. Click **Save**, then test: "APEX, Collaborative Mode: Help me plan a website. Clarify requirements before generating the final prompt."

Gem behavior, attachment support, and instruction length limits may differ by account. This is an **adapted Gem**, not an official universal APEX plugin. Creating a Gem does not grant Gemini access to tools or accounts that aren't enabled.
