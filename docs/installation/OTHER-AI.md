# Use APEX with another AI assistant

There is no verified "one ZIP installs on every chatbot" standard. The most portable route is copying APEX's public instructions.

1. Open [APEX Community Instructions](../../distributions/generic/APEX-COMMUNITY-INSTRUCTIONS.md).
2. Copy their content into the AI assistant's **custom instructions, saved assistant instructions, system-instruction field, or a new chat**, whichever the service supports.
3. If the service has a persistent knowledge or file feature, use it only if permitted and read the provider's instructions first.
4. Start a test with a fictional request: "APEX, Collaborative Mode: Help plan a budget-friendly study timetable; ask only the important questions first."
5. Check that it doesn't invent sources, permissions, model access, or actions.

Some assistants limit prompt size, role priority, memories, or file support. Generic instructions cannot add web access, schedule background tasks, or install plugins.
