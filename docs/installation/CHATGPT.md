# Use APEX in ChatGPT

**Availability varies by account and workspace.** APEX's author's personal plugin is private. The public GitHub ZIP does not install that private plugin into another account.

## Option A: Any chat with copy/paste (simplest)

1. Open [the APEX Community instruction text](../../distributions/generic/APEX-COMMUNITY-INSTRUCTIONS.md).
2. Copy it into a **new ChatGPT conversation**, then send your real task.
3. Example: "APEX, Quick Mode: Turn my informal request into a concise, accurate prompt."
4. A long conversation may require repeating the instructions; there is no guaranteed permanent installation in this option.

## Option B: Skills for eligible accounts

For accounts with ChatGPT personal Skills access, go to **Plugins → Skills**, then use **Create → Upload from your computer** to import a compatible **individual** skill folder/ZIP. This repository has three separate folders under \`skills/\`:
- \`apex-prompt-engineering\`
- \`apex-model-intelligence\`
- \`apex-tool-workflow-intelligence\`

Prepare or upload each folder separately as directed by your account's upload interface; do **not** upload the whole repository ZIP as one skill. Some accounts cannot create personal skills, and organizational restrictions may apply. A skill provides instructions, not automatic tool permissions.

## Option C: Public directory (when approved)

If APEX later receives approval for a public plugin listing, use **Plugins → search for APEX → Install**, subject to your account's eligibility. **This route is not active yet.** Do not claim it is publicly listed.
