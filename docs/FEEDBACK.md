# Feedback and troubleshooting

Thanks for testing APEX Community from Babillail AI Studio!

## Report a problem or idea

1. Consult [the quickstart](../QUICKSTART.md) and your platform guide.
2. Search [existing GitHub Issues](https://github.com/Asbabillail/apex-universal-ai/issues).
3. Click **[Submit APEX Feedback](https://github.com/Asbabillail/apex-universal-ai/issues/new?template=feedback.yml)**.
4. Choose the issue type and AI platform, state the expected result, and include safe steps to reproduce. If you know your APEX version, include it.
5. We review feedback as maintainer capacity permits; this is not guaranteed real-time customer support.

A **free GitHub account** is needed to submit a public issue. GitHub Issues are publicly visible. Use made-up example prompts and remove identifiable or private data before posting. Do not upload private attachments, client information, API keys, passwords, access tokens or screenshots containing sensitive material.

For potential security vulnerabilities, read [SECURITY.md](../SECURITY.md) and contact the maintainer privately if an approved private reporting channel exists; do not post vulnerability details publicly.

## What good feedback looks like

- Platform: Claude
- Version: v3.0.0-alpha.2
- What happened: the skill ZIP was rejected due to packaging.
- Steps: used **Customize → Skills → Upload a skill**, uploaded the entire repository ZIP.
- Expected: skill becomes available.
- Suggested resolution: upload **one skill folder per ZIP**, not the full repository ZIP.

We welcome constructive features, docs corrections, failure cases and reproducible results; avoid fabricated performance claims.
